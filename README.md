# Dance Class Registration Website

## Project Description
A web-based dance class registration website where students can register for dance classes by entering their personal details and selecting their preferred dance style.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub Pages

## Features
- Student registration form
- Name, age and email fields
- Dance style selection
- Registration success message
- Responsive design
- Online deployment using GitHub Pages

## How It Works
1. Student enters their name.
2. Student enters their age and email.
3. Student selects a dance style.
4. Student clicks on Register Now.
5. Registration successful message is displayed.
